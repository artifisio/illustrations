## Install

```bash
npx artifisio add fernforge
```

Recolour at install time; themeable slots: `primary-blue`, `secondary-teal`, `leaf-green`, `accent-orange`.

```bash
npx artifisio add fernforge --colors "primary-blue=#4A7CFF"
```
