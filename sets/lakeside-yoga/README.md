## Install

```bash
npx artifisio add lakeside-yoga
```

Recolour at install time; themeable slots: `primary`, `secondary`, `accent`, `tertiary`.

```bash
npx artifisio add lakeside-yoga --colors "primary=#4A7CFF"
```
