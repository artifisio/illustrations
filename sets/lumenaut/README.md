## Install

```bash
npx artifisio add lumenaut
```

Recolour at install time; themeable slots: `dark-blue`, `teal`, `coral`, `lavender`, `steel`.

```bash
npx artifisio add lumenaut --colors "dark-blue=#4A7CFF"
```
